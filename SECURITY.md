# Security

## Supported versions

Only the latest minor release on `main` is actively supported with security fixes.

## Reporting a vulnerability

Please **do not** open public issues for security reports.

- Use GitHub [private security advisories](https://github.com/security/advisories) if enabled for this repository, **or**
- Email maintainers with a clear subject line and reproduction steps (no destructive payloads).

We aim to acknowledge reports within a few business days.

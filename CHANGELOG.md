## [0.1.0] - 2026-03-29

### Added

- Initial `langgraph-telemetry` Python package: `TelemetryStreamBridge`, `TelemetryCallbackHandler`, Prometheus metrics, optional `/metrics` server
- Next.js dashboard with server-side Prometheus proxy and charts
- Docker Compose + Prometheus scrape config
- `examples/basic_agent` demo loop
- Documentation and OSS community files
